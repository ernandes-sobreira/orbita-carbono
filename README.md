# Órbita do Carbono

**Um quiz interativo sobre o ciclo do carbono — do ar às profundezas do oceano.**

[**Jogar Órbita do Carbono**](https://ernandes-sobreira.github.io/orbita-carbono/) · [Código-fonte](https://github.com/ernandes-sobreira/orbita-carbono)

## Sobre o jogo

Órbita do Carbono é um jogo educativo para estudantes, professores e pessoas interessadas no ciclo do carbono. O objetivo é responder perguntas sobre processos, reservatórios e fluxos de carbono, aprendendo com explicações apresentadas após cada resposta.

A interface combina cenários ambientais e uma representação animada e ilustrativa de um átomo de carbono. A imagem do átomo é uma **representação artística**, não um modelo físico de trajetórias eletrônicas reais.

## Como jogar

1. Abra o jogo pelo link acima.
2. Escolha **Básico**, **Intermediário**, **Difícil** ou **Carbonauta**.
3. Responda às alternativas; depois de cada resposta, leia a explicação científica.
4. Conclua todas as perguntas, confira sua pontuação e informe um nome para entrar no ranking.

**Ranking:** mais pontos = melhor colocação. Em caso de empate na pontuação, vence quem concluir em menos tempo. Acertos consecutivos oferecem bônus de sequência.

Cada dificuldade pode ser jogada de maneira independente.

## Para uso em sala de aula

O quiz pode apoiar aulas de Ecologia, Biologia, Ciências Ambientais e mudanças climáticas. Recomenda-se discutir as justificativas das respostas, comparar as dificuldades e usar o resultado como ponto de partida para perguntas investigativas.

## Recursos

- Quatro níveis de dificuldade, com perguntas embaralhadas.
- Respostas com correção e explicações.
- Painel de acertos, pontos, sequência, tempo e progresso.
- Ranking online por dificuldade, integrado ao Firebase Firestore.
- Interface responsiva para celulares, tablets e computadores.
- Átomo de carbono ilustrativo com elétrons animados.
- Código HTML, CSS e JavaScript em arquivo único.

## Executar

Abra `index.html` em um navegador moderno. O quiz funciona localmente; as funcionalidades do ranking exigem internet, configuração e permissões adequadas do Firebase.

## Tecnologias

HTML5, CSS3, JavaScript e Firebase Cloud Firestore. Publicação por GitHub Pages.
